# Testovací balíčky

Tyto ZIPy jsou určeny pro omezené komunitní testování před prvním stabilním
vydáním. Instalují se v QGIS přes **Zásuvné moduly → Spravovat a instalovat
zásuvné moduly → Instalovat ze ZIP**.

## CzechRad Studio 0.5.5

- soubor: [`czechrad_studio-0.5.5-test.zip`](czechrad_studio-0.5.5-test.zip)
- velikost: 58 388 bajtů
- SHA-256: `105008FD0DABB83C1D85002939FFAEA617C41A3C21903472AFC9DEE58D573302`
- ověření: 80 automatických testů a praktický test v QGIS
- kompatibilita: QGIS 3.22+ / Qt 5 a QGIS 4.x / Qt 6, Windows a Linux

Balíček je experimentální. Před veřejným sdílením LOGů zkontroluj, zda jejich
GPS souřadnice neobsahují citlivou trasu nebo soukromá místa.
